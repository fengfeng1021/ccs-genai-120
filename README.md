# CCS 生成式AI人工智慧核心能力 — 120 題題庫

Pearson VUE / Certiport **Critical Career Skills（CCS）— Generative AI Foundations** 的練習題庫，共 120 題（含答案與解析）。

## 兩種模式

- **逐題模式**：一次顯示一題，點選選項後可顯示答案；手機可左右滑動換題，桌機可用 ← → 鍵。
- **整頁模式**：一頁列出全部題目，正確答案以選取狀態呈現；解析可逐題展開，也可用上方「解析」按鈕全部收合。

## 功能

- 四大考綱篩選（考綱一 30 題、考綱二 32 題、考綱三 28 題、考綱四 30 題）
- 題目關鍵字搜尋
- 答案／解析顯示開關（設定會存在瀏覽器）
- 列印或存成 PDF
- 手機優先版面，支援深色模式

## 內容來源

- 官方考綱：Certiport（台灣總代理碁峰資訊）
- 題庫 1–80 題：整理自公開流傳的 CCS 參考題庫與其解析
- 題庫 81–120 題：依官方考綱子項目自編

答案依官方考綱邏輯整理，**非官方答案鍵**；正式考試以 Certiport 為準。少數題目在社群版本中有疑義者，已於解析中註明。
