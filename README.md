# CCS 生成式AI人工智慧核心能力 — 80 題練習

Pearson VUE / Certiport **Critical Career Skills（CCS）— Generative AI Foundations** 的練習題庫，共 80 題（考綱一 19、考綱二 22、考綱三 18、考綱四 21）。

題目來源：公開流傳的 CCS 參考題庫（考生依官方考綱回憶整理），非官方題庫、非真題。

## 三種頁面

- **搜尋**：看紙本題本時最快的三種找法——
  1. **題號快速跳**：打開 1–80 的數字表，點一下就出答案，還能用「← Q36 / Q38 →」前後翻。
  2. **貼上題目**：用相機（iOS 原況文字／Google Lens）把題目轉成文字後貼上，模糊比對會找到最接近的題目。
  3. **打字搜尋**：中文關鍵字、拼音首字母（`scs`）、全拼（`shengchengshi`）、注音（`ㄕㄔㄕ`）、題號（`42`），簡體字也通。
  結果會直接顯示題目、選項、正確答案與解析，不用再點進去。
- **逐題**：一次一題。單選點下去立刻揭曉對錯；複選與複合題選好後按「確認答案」。
- **整頁**：一頁列出全部 80 題，正確答案以選取狀態標示，解析可收合。

## 作答方式

- 答案預設隱藏；選了才顯示正確答案、對錯，以及解析（錯的題目會直接告訴你為什麼錯）。
- 想先看答案可按底部「看答案」，該題標記為未計分。
- 右上「已答／答對」計數會累計；「重新開始」可清空重練。
- 支援考綱篩選、關鍵字搜尋、列印，手機可左右滑動換題。

## 注意

答案依官方考綱邏輯整理，非官方答案鍵；少數題目在社群版本中有疑義，已在解析中註明。正式考試以 Certiport 為準。
